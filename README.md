# 🎮 猜数字游戏

一个精美的猜数字游戏网页应用，支持统计数据持久化和笔记功能。

## 📋 项目简介

这是一个基于 HTML/CSS/JavaScript 开发的猜数字游戏。玩家需要在10次机会内猜出一个4位不重复的数字。游戏会提供"完全正确"（位置和数字都对）和"仅数字正确"（数字对但位置不对）的反馈，帮助玩家逐步推理出答案。

## ✨ 功能特性

### 核心功能
- 🎯 **智能反馈系统**：每次猜测后会显示"完全正确"和"仅数字正确"的数量
- 📊 **实时统计**：顶部显示游戏次数、胜利次数和平均猜测次数
- 📝 **笔记功能**：右侧笔记区域可记录推理过程，自动保存
- 📋 **历史记录**：左侧显示所有猜测历史及反馈结果
- 💾 **数据持久化**：所有统计数据和笔记自动保存到本地浏览器

## 🚀 快速开始

### 运行方式

**直接打开**https://showlee912.github.io/GuessNumberGame/

### 游戏规则

1. 系统会随机生成一个**4位不重复**的数字
2. 你有**10次机会**来猜测这个数字
3. 每次猜测后会得到反馈：
   - 🟢 **完全正确**：数字和位置都正确的个数
   - 🟡 **仅数字正确**：数字正确但位置不对的个数
4. 根据反馈不断调整，直到猜对或用完机会

## 🎯 功能详解

### 统计数据
- **游戏次数**：记录总共玩了多少局（包括胜利和失败）
- **胜利次数**：成功猜对的局数
- **平均猜测**：获胜时的平均猜测次数（保留1位小数）

### 数据持久化
所有数据都自动保存在浏览器的 LocalStorage 中：
- 游戏统计数据（`guessGameStats`）
- 笔记内容（`guessGameNotes`）
- 刷新页面后数据依然保留
